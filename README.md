# study-performance-analytics-system
A Python-based study performance analytics system designed to help students track productivity, maintain study consistency, analyze weak subjects, and visualize learning patterns through interactive reports and insights.
# Study Performance Analytics System

A Python-based productivity analytics system built using Google Colab.

## Features
- Daily study tracking
- Productivity score calculation
- Goal achievement monitoring
- Streak calendar tracking
- Weak subject detection
- Pie chart productivity analytics
- Weekly bar graph reports

## Tech Stack
- Python
- Google Colab
- Matplotlib

## Future Improvements
- Streamlit web deployment
- AI-powered recommendations
- Long-term analytics dashboard
- User authentication system

## Project Goal
To create a smart study performance analytics system that helps students track productivity, consistency, and weak areas effectively.
